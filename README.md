# BugPet

> 让编程时的专注，成为一只桌面伙伴的成长。

**LukeZ 过往作品独立展示。** 这里是为报名准备的案例介绍，不包含原项目源码或素材；项目详情、协作者与贡献记录以[原项目仓库](https://github.com/eiddiedev/BugPet)为准。

## 项目概览

BugPet 是原生 macOS 桌面宠物，把编码在场、成长反馈与轻量陪伴组合成日常体验。

## 展示重点

- 透明悬浮窗口中的宠物角色可以一直陪伴在桌面。
- 通过前台应用识别与系统空闲状态，感知编码状态。
- 以角色成长与可交互反馈，给专注时间一个可见的结果。

## 技术与体验关键词

Swift · AppKit · SpriteKit
