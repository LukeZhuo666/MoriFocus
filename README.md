# BugPet｜桌面上的专注伙伴

**让编程时的陪伴和进度拥有一个看得见的角色。**

BugPet 是一款面向 macOS 的桌面宠物体验。它将轻量的桌面陪伴与专注状态反馈结合起来，让宠物在用户编程时留在工作空间中，并通过成长反馈记录持续投入的过程。

## 设计出发点

专注工具常以计时器和任务清单呈现进度。BugPet 选择角色陪伴的方式：把抽象的专注时间转化成宠物的存在、状态与成长，让用户在工作间隙也能获得轻量而持续的反馈。

## 核心体验

- **桌面陪伴**：宠物以透明悬浮窗口呈现，可在桌面上移动，不遮挡主要工作界面。
- **状态感知**：结合前台应用和系统空闲状态，判断用户是否处于编程场景。
- **成长反馈**：将持续投入转化为宠物成长，让专注过程更具体、更有记忆点。
- **自然互动**：通过桌面角色与轻量交互，为工作节奏加入短暂的情绪缓冲。

## 产品特点

BugPet 将工具属性与角色关系放在同一个体验里。用户不需要不断切换到单独的打卡页面，就能在日常工作环境中看到陪伴角色和状态变化。

## 项目信息

- **平台**：macOS
- **方向**：桌面宠物、专注反馈、角色化体验
- **技术**：Swift、AppKit、SpriteKit
