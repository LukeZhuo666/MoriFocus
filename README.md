# 芽伴（Mori）

芽伴是一款专注计时与陪伴成长工具。选择一件要做的事，开始 25 分钟专注；每完成一段时间，桌面里的小芽都会获得成长能量。

## 开始使用

打开 [芽伴](https://lukezhuo666.github.io/MoriFocus/)，写下今天的小目标，点击“开始专注”。可以随时暂停、重置计时，或切换到 5 分钟休息。目标完成后勾选即可。

## 功能

- 25 分钟专注与 5 分钟休息计时
- 目标清单，支持完成和删除
- 专注次数、累计时长和伙伴成长等级
- 自动保存进度到当前浏览器
- 离开页面时自动暂停，避免后台计时误差

所有数据仅保存在当前浏览器中，无需登录。
